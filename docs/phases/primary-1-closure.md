## 2. Q-2 — 원소 목록과 타입

### 2-1. 노드

```
Node (t : ℕ) :=
  { 의사결정단위
    대차대조표 : Currency → BalanceSheet
    제약 : (부채측한도, 자산측적격성) }
```

- **노드는 의사결정 단위다.** 법인·단계·데스크·관할권은 노드가 아니라 관측 투영이다
- **제약은 쌍이다.** 부채 측 한도("얼마나 빌릴 수 있는가")와 자산 측 적격성("무엇을 보유할 수 있는가")
- **시점 인덱스를 갖는다** (L-13)

**유도 술어 (노드 속성 아님):** 변환(신용/만기/유동성), 담보공급자, 중앙은행.

### 2-2. 엣지 — 생성 문법

```
원자:  무조건청구권 / 조건부청구권 / 담보부착 / 통화교환다리
합성:  레포 = 담보부착 + 재매입약정
       비소구대출 = 무조건 + 조건부(풋)
       FX스왑 = 통화교환다리 × 2
       준국채 = 위험증권 + CDS + IRS + FX스왑
```

엣지는 유한 열거가 아니라 **합성으로 생성되는 집합**이다.

### 2-3. 그래프는 둘

| 그래프 | 엣지 | 순환 |
|---|---|---|
| 청구권 그래프 | 위 생성 문법의 청구권 | 소유권은 매 시점 유일 |
| 담보 유통 그래프 | 같은 담보의 재사용 경로 | **허용** |

신용중개 연쇄는 청구권 그래프 위의 경로이고 단계 순서를 갖는다. 동적 연쇄는 담보 유통 그래프 위의 경로이고 순서가 없다.

**짭란티어 재유입 시 엣지 집합이 두 개여야 한다.**

### 2-4. 위계

```
Hierarchy (t : ℕ) : PartialOrder Claim
  축1: 받치는 자산이 공적인가 사적인가
  축2: 백스톱이 공적인가 사적인가
```

**전순서가 아니다.** 곱 순서이므로 대각선상 두 사분면이 비교 불가능하다. 전순서가 필요한 명제는 그 지점에서 가정을 명시한다(T-4·T-5).

통화에도 **자금조달 통화 등급**(부분순서, 시점 인덱스)이 필요하다. 위계와의 통합이 방향이나 색인 대응은 미해결(K-7).

## 3. Q-3 — 형식화 판정

### 3-1. 층별 배정

| 층 | 대상 | 수 체계 | 기준선 |
|---|---|---|---|
| 정의층 | 노드·청구권·위계·제약의 구조 | 무차원 + `ℕ` | `[propext, Quot.sound]` |
| 회계층 | 보존 항등식, 담보 장부, 집계 | **`ℤ`** (L-15) | `[propext, Quot.sound]` |
| 동학층 | 제약의 물림 정도, 균형, 되먹임 | `ℝ` | 오염 |
| 관측층 | 측정 사상의 명세 | 무차원 | `[propext, Quot.sound]` |

### 3-2. 재유입 경계

**구성적으로 가능 (재유입 대상):**
- 노드·청구권·위계 타입 전체
- 대차대조표 항등식, 통화별 총액 보존
- 담보 중복 계상 (소유권 장부 / 담보 장부 분리)
- 부채수용력 상한 (선형방정식 표현)
- 제약의 **물림 여부** (승수 = 0인가)
- 집계 정리 **(기계 검증 완료)**

**불가 (동학층 격리):**
- 제약의 **물림 정도** (승수 값)
- VaR의 분위수 표현, GEV·Vasicek·Merton
- 균형 가격, 시장청산
- 되먹임 루프 전체

**판정의 핵심:** 같은 대상도 표현을 바꾸면 층이 바뀐다. VaR 제약은 레버리지 상한(`ℚ`/`ℤ`, 회계층)으로도 분위수(`ℝ`, 동학층)로도 쓸 수 있다. **상한 표현이 정본이다.**

### 3-3. 기계 검증된 것

현재 1건.

```
two_mul_aggregationError_eq_pairwise        [propext, Quot.sound]
aggregationError_eq_zero_of_constant_cap    [propext, Quot.sound]
aggregationError_eq_zero_of_constant_equity [propext, Quot.sound]
```

Mathlib `v4.32.2` / 커밋 `905b958`. 변이 검사 5개 진술 전량 거부.

**이 정리가 준 것:** 집계 오차 = 노드 쌍마다 (제약 차이 × 규모 차이)의 합. 따라서 **노드를 쪼개야 하는 조건은 "제약이 다르다"가 아니라 "제약이 다르고 규모도 다르다"** 이다. 원 문헌의 집계 주장은 정리가 아니라 따름정리였다.

## 5. 초석 명제의 현재 상태

세션 시작 시점의 명제:

> 모든 경제 문제는 돈을 안/못 갚아서 발생한다.

PH-1 종료 시점:

> **위기는 상환 실패 가능성에 대한 평가가 바뀌어 제약이 조일 때 발생한다.**
> 네트워크를 타고 전파되는 것은 손실이 아니라 **담보 가용성과 그에 따른 부채수용력**이다.
> 실제 상환 실패는 위계 하단에서 일어나며, 상단의 노드는 디폴트하지 않고 조정한다.

**세 수정 모두 뭉치의 서로 다른 논문에서 독립적으로 나왔다.** 디폴트 없는 증폭이 세 논문에서 각각 확인됐고(계약 해에서 부도확률 0), 담보 가용성 전파는 회계틀에서, 위계 하단 이동은 통화 축 논문에서 나왔다.

**`미형식화` 표시 대상:** "위기 규모가 네트워크 연결 구조에 비례한다"는 절은 현 뭉치에서 지지되지 않는다. PH-4까지 N-2에 따라 표시한다.

## 6. PH-2로 넘어가는 것

### 6-1. 다음 형식화 대상

**청구권 타입이 선행 조건이다.** 회계층의 남은 대상이 전부 청구권을 요구한다.

| 대상 | 필요한 것 |
|---|---|
| 복식부기 폐쇄성 | 청구권이 양쪽 노드에 동시에 잡힘 |
| 통화별 총액 보존 (L-12) | 통화로 색인된 청구권 |
| 담보 중복 계상 | 담보 부착 청구권 + 담보 장부 |
| 부채수용력 | Π 행렬 = 청구권 보유 구조 |

집계 정리가 청구권 없이 된 것이 예외였다. `cap` 과 `equity` 가 스칼라라 노드 내부만 보면 됐기 때문이다.

### 6-2. 예고되는 난점

**수치 파라미터화의 재귀.** `Constraint` 에서 `Num` 파라미터로 푼 문제가 청구권에서 다시 나온다. 청구권은 재귀 생성자(담보부착이 Claim을 받음)를 가지므로 파라미터가 재귀를 타고 흐른다.

**조건부 청구권과 C-3의 충돌.** 보증·신용라인·풋의 발동조건을 `Prop` 으로 두면 판정 불가가 되어 C-3과 P-2에 걸린다. `Bool`·유한 열거·`Decidable` 파라미터 중 무엇을 택해도 표현력을 잃는다. **이는 회피할 문제가 아니라 P-1이 찾는 종류의 구멍일 가능성이 높다.** 조건부 청구권은 계약서에 자연어로 쓰인 것이고, 그것이 판정 가능한 술어로 환원되지 않는다는 것이 사실일 수 있다.

### 6-3. 병행 가능

지목 대기 문헌 2편(H-02, H-22)은 청구권 타입을 막지 않는다. 청구권은 구조이고 그 둘은 상태에 관한 것이다.

관측층은 정의층 대상이 서기 전에는 채울 것이 없다(L-14).
