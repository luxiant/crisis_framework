# 추출 기록 E-31

**Ma · Schmidt-Eisenlohr (2023), "The Financial Channel of the Exchange Rate and Global Trade"**
배정: **뭉치 · 교역 금융과 결제 방식 · 지목 참조 (S-7)** | 단계: **PH-2** | 상태: **부분 추출** (초록과 한 절)
목적: **결제 정보를 가진 세관 자료의 소재 확인**

**S-4 의 포화 카운트에 들지 않는다.** 구간 순서 밖에서 지목으로 왔다.

---

## 0. 이 논문의 지위

달러가 강해질 때 미국 밖 나라 사이의 교역이 금융 경로로 주는지를 본다. **이번에는 초록과, 세관 자료를
언급한 서론의 한 자리만 읽었다.** 본문은 `claim-6` 이 교역 금융의 통화를 다룰 때 읽으며, 그때 이 기록에
덧붙인다(§2.5).

---

## 1. §4.5 템플릿 (부분)

| 슬롯 | 값 |
|---|---|
| **노드** | 미국 밖 나라의 수출기업과 수입기업 |
| **통화 축** | **주 대상.** 교역의 표시 통화가 달러가 아니어도 금융이 달러로 조달된다 |
| **되먹임 방향** | 달러가 강해지면 수입 가격이 오르고 물량이 준다. 수출국의 해외 차입에서 달러 비중이 클수록 그렇다 |
| **형식층 배정** | **관측층**(세관 자료의 소재) / **동학층**(환율의 금융 경로) |
| **형식화 판정** | 이번 읽기 범위에서는 관측층의 소재 하나만 이행된다 |

나머지 슬롯은 본문을 읽은 뒤 채운다.

---

## 2. 구조

### 2-1. 결제 정보를 가진 세관 자료

교역 거래 전량을 덮으면서 결제 정보를 가진 세관 자료가 터키와 칠레와 콜롬비아에 있다고 적는다. 그
자료에서 무역신용이 국제 교역 흐름의 대부분을 차지한다.

### 2-2. 금융 경로

달러가 강해지면 달러가 아닌 통화를 쓰는 나라 사이에서도 수입 가격이 오르고 물량이 준다. 저자들은 이것을
교역의 금융이 달러로 조달되기 때문으로 읽는다.

---

## 3. 새 원소

### 3-1. 세관 경로가 있는 나라

경로 명세의 표에서 세관 경로가 칠레 하나가 아니라 셋임을 이 편이 준다. 나라마다 칸의 구성은 다를 수
있다. 터키 자료를 쓴 다른 연구가 은행이 끼는 결제를 선지급과 한 칸에 모았다는 것을 E-26 이 전한다.

### 3-2. 교역 금융의 통화는 교역 표시 통화와 갈린다

E-19 와 같은 축이며 CQ-fin-2 의 재료다. `claim-6` 이 받는다.

## 8. 덧붙임 — 본문 (`claim-6`, 2026-10-01)

§0 이 예고한 대로 `claim-6` 이 본문 전량을 읽었다. **앞 문면은 고치지 않는다.** §1 의 표도 그대로
두고, 채우지 못했던 슬롯을 아래 8-1 에 다시 놓는다(§2.5).

**앞 문면 가운데 낡은 자리 하나.** §0 과 §3-2 가 지목하는 B-1 은 `claim-5` 에서 폐기됐고 B-6 이
대체한다. 이 기록은 역사 기록이므로 그 자리를 고치지 않는다.

### 8-1. §4.5 템플릿 (완성)

| 슬롯 | 값 |
|---|---|
| **노드** | 미국 밖 나라의 수출기업과 수입기업. 분석의 단위는 나라 쌍이다 |
| **소유 법인** | 다루지 않는다 |
| **통화 축** | **주 대상.** 교역의 표시 통화와 교역 금융의 조달 통화를 별개 축으로 둔다 |
| **제약 형태** | 금융 중개의 위험 감수 능력. 달러가 강해지면 조인다 |
| **제약의 인자** | 수출국의 대외차입 가운데 달러 표시의 몫, 달러 환율 |
| **조정 여지** | 수출 가격과 수출 물량 |
| **화폐성 위계 위치** | 없다 |
| **담보 재사용** | 없다 |
| **부외 여부** | 없다 |
| **되먹임 방향** | 달러 강세 → 중개기관의 대차대조표 압박 → 교역 금융 축소 → 수출 가격 상승과 물량 감소 |
| **형식층 배정** | **관측층**(세관 자료와 통화 구성 자료의 소재) / **동학층**(환율의 금융 경로) |
| **형식화 판정** | 관측층의 소재 둘과 두 축의 비대칭이 이행된다. 경로의 크기는 동학층이므로 재유입에서 빠진다(PH-R2) |

### 8-2. 교역 금융의 통화를 직접 재지 않는다

저자들이 쓰는 측도는 **수출국의 대외부채 가운데 달러 표시가 차지하는 몫**이다. 자료는 Bénétrix 외의
국제투자대조표 통화 구성이고(E-41), 대안 측도도 같은 자료에서 만든 순 달러 부채 대 GDP 비다.

**교역을 금융한 청구권의 통화가 아니라 나라 전체의 대외차입 통화 구성이다.** CQ-fin-2 가 묻는 것과
이 편이 재는 것 사이에 칸이 둘 빈다. 그 차입이 교역을 금융했는지가 하나이고, 그것이 어느 나라 쌍의
어느 품목에 붙는지가 다른 하나다.

### 8-3. 품목 축이 교역 쪽에만 붙는다

HS 6단위의 품목 수준 회귀가 있고 자료는 CEPII-BACI 다. 그런데 **품목 수준에서도 금융 측도는 여전히
나라 수준이다.** 품목 고정효과를 넣을 뿐 금융 쪽에 품목 축이 생기지 않는다.

### 8-4. 두 축이 서로 다른 나라에 붙는다

금융 경로는 수출국의 달러 차입 몫에 걸리고, 표시 통화 경로는 수입국의 달러 표시 몫과 환율에 걸린다.
그래서 수입국·연도 고정효과를 넣으면 표시 통화 경로가 통째로 흡수되고 금융 경로만 남는다. 식별 전략
자체가 두 축의 분리를 딛는다.

근거는 **교역을 대부분 수출자가 금융한다**는 것이며, 저자들이 이것을 추정 결과가 아니라 전제로 쓴다.

### 8-5. 대차대조표 효과의 층위를 셋으로 뭉뚱그린다

기업과 은행과 글로벌 기관투자자다. 저자들이 자기 추정치가 셋을 함께 담으며 그것을 가르지 않는다고
명시한다. E-18 이 의사결정 단위와 회계 단위의 대응을 자인한 것과 같은 자리다.

### 8-6. 봉합하지 않은 차이 하나 (B-7)

세관 자료 세 나라에서는 무역신용이 교역 흐름의 대부분을 차지하는데, Antràs · Foley 가 본 한 미국
수출기업에서는 무역신용과 선지급이 훨씬 고르게 갈렸다(E-25). 저자들이 이 차이를 각주에 그대로 적고
봉합하지 않는다.

### 8-7. 새 원소

- **8-a.** 교역 금융의 통화에 대한 문헌 최전선의 측도가 나라 수준 대리다(8-2). **(나) 의 셋째 칸**
- **8-b.** 품목 축이 교역 쪽에만 붙는다(8-3)
- **8-c.** 두 통화 축이 서로 다른 나라에 붙는다(8-4). E-19 의 「별개 축」이 색인으로 정교해진다
- **8-d.** 대차대조표 효과의 층위가 문헌에서도 서지 않는다(8-5)

### 8-8. Q-4 기여

신규 구멍 없음. 8-a 는 E-41 이 소스 쪽에서 받고, 8-d 는 `CF-619` 가 당사자 타입을 매개변수로 둔
판정에 받쳐진다.

### 8-9. B-3 준수 확인

**구조로 판단해 기록한 것:** 측도의 정의와 그 자료의 출처, 품목 축이 붙는 자리, 두 경로의 색인 차이와
그것을 쓰는 식별 전략, 층위를 가르지 않는다는 자인, 각주가 적은 문헌 간 차이.

**추출하지 않은 것:** 회귀 계수와 유의성, 표본의 나라 수와 관측 수, 달러 차입 비중의 평균과 순위,
도구변수의 1단계 통계량.
