## 2. 층별 배정 상세

### 정의층 (무차원, 구성적 가능)

- **노드 = 대차대조표.** 자산 / 부채 / 자본 세 필드
- **레버리지** λ = A/E (무차원 비율)
- **헤어컷** = 1/λ = 1 − q*. 논문의 `λ* ≡ 1/(1−q*)`가 이 항등식이다
- **VaR 규칙의 구조.** "제약 변수가 자본과 같게 유지된다"는 형태. 제약 변수의 값이 아니라 **등식의 형태**만 취하면 무차원

### 회계층 (정확 산술, 구성적 가능)

- **대차대조표 항등식** A = D + E
- **레버리징 3모드 분할** (논문 Figure 1). 무엇을 고정한 채 레버리지를 올리는가로 분류:
  - Mode 1 — 자산 고정 (부채발행으로 자사주 매입)
  - Mode 2 — 부채 고정 (자산가격 변동 또는 자산매각 배당)
  - Mode 3 — **자본 고정** (차입으로 자산 확대)
- 실증 결과: 딜러는 Mode 3이다. 자본이 고정된 축이다
- **완전성이 실제로 증명된다.** A = D + E의 세 성분 중 하나를 고정하는 것이므로 세 모드가 전부다. §4-3 참조

### 동학층 (`ℝ`, 비구성적)

- **VaR 자체.** 분위수 정의: 손실이 V를 넘을 확률이 1−c 이하가 되는 최소 V. 분포 위의 실수
- **GEV 분포족** (Fisher-Tippett). 파라미터 δ(위치), σ(척도), γ(형상)
- **계약 문제의 해와 Proposition 1**

## 3. 형식화 판정

| 대상 | 판정 | 비고 |
|---|---|---|
| 대차대조표, A=D+E | 구성적 가능 | `ℤ`/`ℚ`. 회계층 |
| 레버리지 λ = A/E | 구성적 가능 | `ℚ`. `Decidable` 비교 가능 |
| 레버리징 3모드 분할 | 구성적 가능 | `inductive`. 완전성 증명 가능 |
| 헤어컷 = 1/λ | 구성적 가능 | 위와 동일 대상의 역수 |
| VaR 규칙 (제약 상한 형태) | 구성적 가능 | `λ ≤ λ*` 로 쓰면 `ℚ`. 회계층 유지 |
| VaR 규칙 (분위수 형태) | **불가** | `ℝ` + 측도. 동학층. L-4 위반이므로 회계층 진입 금지 |
| GEV 분포족 | **불가** | Mathlib 수록 여부 미확인. 수록되어도 `Classical` 전파 |
| Proposition 1 (부도확률 불변) | **판정 보류** | 위 두 항목에 의존. 진술 자체가 동학층 |

**핵심 판정:** 같은 VaR 제약이 **두 가지 표현을 가지며 서로 다른 층에 놓인다.** 레버리지 상한으로 쓰면 회계층에 남아 구성적이고 재유입 가능하다. 분위수로 쓰면 동학층으로 가고 재유입 대상에서 빠진다(PH-R2). K-6이 추상적 문제가 아니라 첫 논문에서 바로 물린다.

## 4. Q-1 기여 — 용어 분할

### 4-1. 확정 분할: **레버리지** (G-1 충족)

| 하위 개념 | 정의 | 측정 소스 |
|---|---|---|
| 장부 레버리지 | 총자산 / 장부자본 | 10K·10Q |
| 기업가치 레버리지 | (시가총액 + 부채) / 시가총액 | 주가 + 10K·10Q |

저자가 후자를 **명시적으로 기각**하고 전자를 채택한다. 기각 사유도 명시: 관심 대상이 은행의 대출 행위, 즉 자산 포트폴리오이지 기업가치가 아니기 때문. 규율 D-2의 3항(기각한 대체 정의 후보와 사유)이 원문에서 그대로 조달된다.

D-3 배제 사례: 동일 기간 동일 기관에 대해 두 지표의 산점도가 서로 다른 모양을 보인다(논문 Figure 3 좌우 패널). 장부 기준으로는 Mode 3이지만 기업가치 기준으로는 그렇지 않다.

### 4-2. 확정 분할: **자본** (G-1 충족)

| 하위 개념 | 측정 소스 |
|---|---|
| 장부자본 | 10K·10Q |
| 시가총액 | 주가 |
| 시가평가된 장부자본 | 레포 헤어컷 |

저자가 셋이 서로 다름을 명시한다. 시가총액은 시가평가된 장부자본과 같지 않다. 시가총액에는 포트폴리오와 무관한 수수료 수익의 현재가치가 들어가기 때문. 시가평가된 장부자본의 가장 순수한 사례는 담보부 차입의 헤어컷이다.

### 4-3. 확정 분할: **레버리징 방식** (신규 — 후보 목록에 없던 것)

Mode 1 / Mode 2 / Mode 3. 고정되는 대차대조표 성분으로 분할.

**V-3 관련 발견.** V-3은 `inductive` 분할의 완전성이 증명이 아니라 가정이라고 규정했다. 그런데 이 분할은 다르다. 비형식 개념을 쪼갠 것이 아니라 **회계 항등식의 형식적 귀결**이다. A = D + E에서 고정할 성분을 고르는 것이므로 완전성이 실제로 증명된다.

→ V-3의 적용 범위를 "비형식 개념의 분할"로 한정하는 규율 정교화가 필요하다. 형식 대상의 분할은 완전성이 증명 가능하며 기여 목록에 계상할 수 있다.

### 4-4. 부분 분할: **위험** (G-1 충족하나 잔여 구멍)

| 하위 개념 | 측정 소스 | 시점 |
|---|---|---|
| 자사 측정 위험 (단위 VaR) | 10K·10Q 공시 VaR / 자산 | **후행** |
| 시장 측정 위험 (내재변동성) | 주식 옵션 가격 | 선행 |

두 계열의 정점이 약 6개월 어긋난다. 내재변동성은 2008년 12월, 단위 VaR는 2009년 6월. 사유는 VaR 추정이 과거 데이터 창에 기반하기 때문.

**잔여 구멍:** "실제 위험"에는 이 논문 안에 측정 대응이 없다. §4-4는 측정된 위험 두 종류를 나눴을 뿐 측정된 위험 대 실제 위험의 축은 건드리지 못했다. G-3에 따라 Q-4로 이관.

## 6. PH-R3(화폐성 위계) 진전

J-4의 파생 가설은 "화폐성 위계 = 제약 느슨함의 순서"였다. 이 논문이 첫 재료를 준다.

`λ = 1/헤어컷` 이므로, 헤어컷은 담보의 위계상 위치를 나타내면서 동시에 보유자의 대차대조표 여력을 결정한다. 즉 **헤어컷이 위계와 제약을 잇는 단일 변수 후보**다.

단, 이 논문의 헤어컷은 은행 전체에 대한 스칼라 하나다. 담보 종류별 헤어컷 구조는 없다. 위계를 순서 구조로 만들려면 담보 종류별 헤어컷이 필요하며, 그 재료는 O-2(Pozsar·Singh)에서 조달해야 한다.

## 7. B-3 준수 확인

추출하지 않은 것: 회귀계수(로그 단위VaR에 대한 로그 레버리지의 계수 −0.38 ~ −0.48), 유의수준, 표본 크기, R². 이들은 구조가 아니라 실증 결과이므로 B-3에 따라 제외.

단, **계수가 −1에 못 미친다는 사실 자체는 구조적 정보**로 판단해 기록한다. VaR 규칙이 정확히 성립하면 −1이어야 하는데 그렇지 않다. 위기 국면(2007Q3–2009Q4)에서만 기울기가 −1에 근접한다. 즉 **VaR 규칙은 상시 성립하는 제약이 아니라 제약이 물렸을 때 드러나는 제약**이다. 이는 형식화 시 제약을 항상 등식(`VaR = E`)이 아니라 부등식(`VaR ≤ E`)으로 두어야 한다는 것을 뜻한다.

→ **H-07 후보:** 제약을 등식으로 둘 것인가 부등식으로 둘 것인가. 등식은 논문의 규칙 진술이고 부등식은 논문의 실증이 지지하는 형태다. 부등식으로 두면 "제약이 물린 상태"와 "물리지 않은 상태"가 구분되고, 이는 위기와 평시를 구분하는 정의가 된다.
