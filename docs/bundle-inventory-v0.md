# 뭉치 인벤토리 v0 (2026-09-12)

**이 목록이 뭉치다.** 무엇이 뭉치에 드는지는 이 목록이 정하며(B-6), 원장은 구성원을 열거하지 않는다.
뭉치가 자라면 이 목록을 고치고, 그 변경은 이 문서의 이력으로 남는다. 참고자료 목록이므로 규율을
담지 않는다.

**뭉치와 zip 은 같지 않다.** 구성원 대부분은 `macro_models.zip` 에 들어 있으나, zip 밖에서 열람한
문헌도 이 목록에 오르면 구성원이며 그 경우 열람처를 적는다. zip 안에서 내용이 같은 사본은 구성원을
늘리지 않으므로 「중복」 절이 따로 센다.

**배정은 읽기의 무리다.** O-1 부터 O-3 까지는 계열로 정한 읽기 구간이고 ★ 는 필독이다. S-4 가
포화 판정을 비★ 구간에만 걸므로 ★ 는 전부 읽는다. 세 계열 밖에서 들어온 문헌은 O-구간에 넣지 않고
무리를 따로 세우며, 구멍에 직결되는 편은 S-7 의 지목 참조로 읽는다.
